# Phoenix 3.0 - Roadmap Inicial

## Objetivo

Estabelecer a base do Phoenix 3.0 com evolucao segura, incremental e testavel, sem quebrar os fluxos atuais do app desktop.

## Bloco 0 (concluido)

- Versionamento atualizado para 3.0.0.
- Constantes centrais de versao sincronizadas.
- README atualizado para refletir a nova fase.
- Documento de roadmap criado para orientar os proximos blocos.

## Principios de execucao

- Compatibilidade retroativa por padrao.
- Entregas pequenas e verificaveis.
- Testes e smoke checks a cada bloco.
- Sem dependencia obrigatoria de servicos externos.

## Proximos blocos (visao geral)

- Bloco 1: consolidacao de contratos internos (core, eventos, modulos).
- Bloco 2: evolucao da camada de dados e migracoes.
- Bloco 3: recursos avancados de produtividade e inteligencia local opcional.
- Bloco 4: refinamentos de UX, observabilidade e hardening.
