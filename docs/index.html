Por que Phoenix

Construido para durar.
Construido para voce.

Sem assinatura mensal. Sem dados na nuvem. Sem dependencia de internet. Apenas sua vida, organizada do jeito certo.

100% Local-first
Todos os dados ficam no seu computador em um arquivo SQLite. Nenhum byte sai da sua maquina sem sua permissao.
phoenix.db - SQLite
Interface nativa
PyQt6 puro, sem Electron, sem browser embutido. Desempenho nativo, atalhos de teclado reais e visual que respeita o SO.
PyQt6 - QSS Dark/Light
Dados reais, graficos reais
PyQtGraph para series temporais em tempo real e Matplotlib embeddado para visualizacoes estaticas. Nao e mock.
PyQtGraph - Matplotlib
Backup e exportacao
Exporta extrato financeiro em PDF via ReportLab, importa CSV e faz backup criptografado do banco inteiro em um arquivo.
ReportLab - Cryptography
Pomodoro nativo
Timer circular desenhado com QPainter, notificacao nativa ao completar, historico de sessoes e estatisticas semanais.
QPainter - QSoundEffect
Kanban com drag and drop
Drag and drop nativo Qt com QDrag e QDropEvent. Nenhum workaround de selecao - arrastar de verdade entre colunas.
QDrag - QDropEvent

Instalacao

Tres comandos.
Pronto.

Nenhuma conta necessaria. Nenhum servidor para configurar. Funciona no Windows, macOS e Linux.

bash - phoenix
# 1. clonar o repositorio
$ git clone https://github.com/Thiago-code-lab/projeto-phoenix
$ cd projeto-phoenix
# 2. criar ambiente virtual e instalar dependencias
$ python -m venv .venv && source .venv/bin/activate
$ pip install -r requirements.txt
# 3. rodar a aplicacao
$ python main.py
✓ banco phoenix.db criado automaticamente
✓ Phoenix 2.0 iniciado com sucesso
