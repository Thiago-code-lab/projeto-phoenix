Projeto Phoenix 2.0

Aplicacao desktop local-first para gestao pessoal com PyQt6, SQLAlchemy e SQLite. Esta pagina existe para publicacao no GitHub Pages e documentacao rapida do projeto.

PyQt6 SQLAlchemy SQLite pytest
Como executar localmente Sobre GitHub Pages 
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python -m phoenix.main

Deploy automatico via GitHub Actions + GitHub Pages.
