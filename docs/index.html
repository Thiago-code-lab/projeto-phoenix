Por que Phoenix

Forjado para Durar

Assim como a fênix renasce das cinzas mais forte, este sistema sobrevive a tudo — cortes de internet, servidores caídos, assinaturas canceladas. Seus dados existem enquanto existir seu HD.

I
100% Local-first
Todos os dados ficam no seu computador em um arquivo SQLite. Nenhum byte sai da sua máquina sem sua permissão.
phoenix.db · SQLite
II
Interface Nativa
PyQt6 puro, sem Electron, sem browser embutido. Desempenho nativo e visual que respeita o sistema operacional.
PyQt6 · QSS Dark/Light
III
Dados Reais
PyQtGraph para séries temporais em tempo real e Matplotlib embeddado para visualizações estáticas. Não é mock.
PyQtGraph · Matplotlib
IV
Backup & Exportação
Extrato financeiro em PDF via ReportLab, importação CSV e backup criptografado do banco inteiro em um arquivo.
ReportLab · Cryptography
V
Pomodoro Nativo
Timer circular desenhado com QPainter, notificação nativa, histórico de sessões e estatísticas semanais integradas.
QPainter · QSoundEffect
VI
Kanban Drag & Drop
Drag and drop nativo Qt com QDrag e QDropEvent. Nenhum workaround — arrastar de verdade entre colunas.
QDrag · QDropEvent

Invocação

Três Comandos.
A Fênix Desperta.

Nenhuma conta necessária. Nenhum servidor para configurar. Funciona em Windows, macOS e Linux.

bash · phoenix
# I · clonar o repositório
$ git clone https://github.com/Thiago-code-lab/projeto-phoenix
$ cd projeto-phoenix
# II · criar ambiente e instalar
$ python -m venv .venv && source .venv/bin/activate
$ pip install -r requirements.txt
# III · despertar
$ python main.py
✦ banco phoenix.db criado automaticamente
✦ Phoenix 2.0 despertou com sucesso
